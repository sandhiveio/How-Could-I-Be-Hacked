# README illustrations

- `investigation-cover.png`: generated with the built-in ImageGen tool, then visually reviewed. The illustration is conceptual, not evidence of an executed investigation.
- `workflow.svg`: editable workflow diagram with explicit colors for light and dark GitHub themes, accessible title and description, and no external dependencies.

## Cover generation prompt

Use case: illustration-story. Asset type: wide GitHub README cover for an open-source security investigation library, landscape 3:1 composition. Create an elegant technical sketchbook editorial illustration on warm off-white paper. On the left a small outlined source-code document with abstract code lines and curly braces. From it graphite investigation paths branch across the page, with small evidence notes and magnifying details, several paths ending in understated crossed-out dead ends. One clear burnt-orange path moves through a magnifying glass inspecting a code boundary, then reaches a small green verified check and a regression-test document on the right. Precise ink drafting, subtle hand-drawn texture, generous whitespace, quiet sophisticated open-source developer aesthetic. Flat frontal composition, graphite outlines, burnt-orange accent and muted forest-green only at verification. Visual metaphor for retrieving hypotheses and testing applicability locally, not an automatic scanner. No people, hooded hackers, locks, shields, neon, gradients, 3D, logos, title, letters, words, numbers or watermark. Keep all meaningful artwork within generous margins.
