## Decision basis and follow-up

No new security vulnerability was confirmed in the performed checks. The required keyword
behavior held, the controls matched, and the ordinary suite passed. The local review retained
two passing regression artifacts for the control matrix and its base/head comparison.

A separate **pre-existing functional observation, priority low**, concerned alternate-salt
timed-file loading. The file roundtrip raised `BadTimeSignature` on both revisions while
direct loading of the identical token succeeded. It was attributed to existing file-wrapper
argument forwarding and recorded for separate repair and regression work. No repaired
revision was assessed in this review.
