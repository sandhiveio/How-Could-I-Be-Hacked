# Security policy

Use GitHub's private reporting form to report a security or privacy issue in How Could I Be Hacked.
The policy covers the skill, its local CLI, and the published library. It also covers accidental
disclosure of sensitive information in public library artifacts.

1. Open [Security advisories](https://github.com/sandhiveio/How-Could-I-Be-Hacked/security/advisories).
2. Select **Report a vulnerability**.
3. Include the affected component, the version or commit if known, and the observed impact.
   For a disclosure in the library, include the public artifact link.

For a finding in a project you reviewed with the skill, use that project's disclosure channel.
